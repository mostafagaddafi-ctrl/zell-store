# ZELL — متجر أفلام الزجاج بالمتر

متجر إلكتروني لبيع أفلام حماية الزجاج للبيوت والشقق **بالمتر الطولي**، مع لوحة تحكم كاملة
لإدارة الطلبات والمنتجات والأسعار والشحن. الدفع عند الاستلام، والتوصيل لكل محافظات مصر.

خامات: **3M** و **V-KOOL** — عازل حرارة، مصنفر (خصوصية)، فاميه أسود.

## نظرة سريعة

**صفحة البيع (`/`)**
1. الزبون يختار نوع الفيلم من ٣ كروت فيها ألبوم صور.
2. يحدد المقاس: **بمقاس الشباك** (عرض × ارتفاع بالسنتيمتر) أو **بالمتر** مباشرة.
3. السعر بيظهر لحظياً ← يضيف للسلة ← يكمل بـ ٤ خانات بس ← رقم الطلب.

**صفحة المنتج (`/product/:id`)** — ألبوم صور بتكبير ملء الشاشة، المواصفات، واختيار المقاس.

**لوحة التحكم (`/admin`)** — ملخص المبيعات، جدول الطلبات، إدارة المنتجات والصور والأسعار،
إعدادات الشحن والواتساب والإشعارات، ومؤشر جاهزية المتجر.

## قاعدة البيانات

أربع جداول — كل الأرقام integer: الفلوس بالقرش، الأطوال بالسنتيمتر.

| الجدول | الوظيفة |
| --- | --- |
| `products` | السعر للمتر، عرض الرول، أقل طول، الخطوة، الصور، الماركة |
| `orders` | رأس الطلب: بيانات العميل، الإجماليات، الحالة، حالة الإشعار |
| `order_items` | أصناف السلة بلقطة مجمّدة من المنتج وقت الشراء |
| `settings` | مفتاح/قيمة jsonb: واتساب، شحن المحافظات، آراء، معرض، لوجو |

الإنشاء الكامل في `backend/db/schema.sql`.

## منطق التسعير

```
سعر الصنف (بالقرش) = round(سعر المتر × الطول بالسنتيمتر ÷ 100)
عدد الشرايح = ceil(عرض الشباك ÷ عرض الرول)
الطول المطلوب = الشرايح × ارتفاع الشباك، مقرّب لأعلى لأقرب خطوة مسموحة
```

كل الحسابات المعتمدة بتتم في الداتابيز داخل **عبارة SQL واحدة ذرّية**،
وأي سعر جاي من المتصفح بيتجاهل. صفر صفوف = الطلب مرفوض برسالة واضحة.
