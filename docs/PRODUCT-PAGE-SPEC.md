# صفحة المنتج — المتطلب المعتمد (للكوميت ٣)

مسجّل الآن، **مش منفّذ في الكوميت ٢**. الكوميت ٢ للصفحة الرئيسية فقط.

## الترتيب الإلزامي

### ١) معرض صور مضغوط

- صورة رئيسية **متوسطة** — ممنوع صورة بملء الشاشة.
- من ٣ لـ ٥ مصغّرات تحتها.
- الضغط على المصغّرة يغيّر الصورة الرئيسية.
- أزرار **السابق / التالي** واضحة.
- الضغط على الرئيسية يفتح **lightbox** (اختياري).
- المعرض **ما ياخدش الصفحة** — خصوصًا على الديسكتوب.

### ٢) معلومات المنتج

اسم المنتج · وصف واضح · أهم المميزات · السعر للمتر · عرض الرول · أقل كمية.

### ٣) اختيار المقاس

- وضع **عرض × ارتفاع** الشباك.
- وضع **بالمتر** مباشرة.
- عرض **عدد الشرايح** و**الطول المطلوب**.
- السعر يتحدّث **لحظيًا**.
- 🔒 **الحفاظ على الخطأ الصريح** لما المقاس يتعدّى الحد الأقصى — ممنوع القص الصامت.

### ٤) إضافة للسلة

زر واحد واضح، وبعده: «كمّل تسوّق» أو «افتح السلة».

## التوزيع

| الشاشة | الترتيب |
| --- | --- |
| ديسكتوب | معرض مضغوط في جانب · المعلومات واختيار المقاس في الجانب التاني |
| موبايل | معرض مضغوط ← الوصف ← اختيار المقاس |

## الصور المتاحة

لكل منتج: **صورة Preview رئيسية + ٤ صور** — بيتوصلوا من Supabase لاحقًا.
خانات `ImageSlot` جاهزة بالنسب الصح فمفيش إعادة تصميم ولا layout shift وقت التوصيل.

| الخانة | النسبة |
| --- | --- |
| الصورة الرئيسية | 1:1 |
| المصغّرات | 1:1 |
| كارت المنتج (الرئيسية) | 4:3 |
