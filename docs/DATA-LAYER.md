# طبقة القراءة — المتجر

قراءة فقط. مفيش أي كتابة على قاعدة البيانات أو Storage من المتجر.

## الحالة

الطبقة **مكتوبة ومش مستخدمة**. المصدر الفعلي لسه `fallback`.
التبديل لـ `supabase` في كوميت منفصل بعد ضبط متغيرات Vercel والمراجعة.

## اختيار المصدر — صريح دايمًا

```text
STOREFRONT_DATA_SOURCE=fallback    # GitHub Actions + التطوير المحلي
STOREFRONT_DATA_SOURCE=supabase    # Vercel بعد ضبط المتغيرات
```

`source.ts` بيقبل القيمتين دول بس. **قيمة ناقصة أو غير معروفة = خطأ صريح** —
مفيش استنتاج من `process.env.VERCEL` ولا رجوع ضمني للكتالوج. خطأ إعداد
صامت بيوصل للزباين بأسعار قديمة من غير ما حد ياخد باله.

## متغيرات البيئة

| المتغير | المكان | ملاحظة |
| --- | --- | --- |
| `STOREFRONT_DATA_SOURCE` | Vercel + GitHub Actions | مش سر |
| `SUPABASE_URL` | Vercel (سيرفر) | مش سر بطبيعته لكن مايتعرضش من غير داعي |
| `SUPABASE_READ_KEY` | Vercel (سيرفر) | 🔒 المستهدف — دور قراءة محدود |
| `SUPABASE_SERVICE_ROLE_KEY` | Vercel (سيرفر) | 🔒 ⚠️ مؤقت — بيتخطى RLS بالكامل |

**ممنوع تمامًا** أي واحد منهم يبقى `NEXT_PUBLIC_`. ترتيب المفاتيح:
`SUPABASE_READ_KEY` الأول، وبعدين `SUPABASE_SERVICE_ROLE_KEY`، ولو مفيش
ولا واحد ← خطأ.

> الـ service-role حل انتقالي للاتصال الأول. لازم يتبدل بدور قراءة محدود،
> والاستبدال وقتها = متغير بيئة واحد من غير أي تعديل كود.

## الاستعلامات

أربع طلبات **متوازية** (`Promise.all`) — مش رحلة شبكة واحدة؛ بينتهوا في
وقت أبطأ واحد فيهم.

| الجدول | الفلتر | الترتيب |
| --- | --- | --- |
| `products` | `is_active = true` | `sort_order asc, id asc` |
| `product_images` | `kind = 'gallery'` | `is_primary desc, sort_order asc, id asc` |
| `settings` | قائمة المفاتيح العامة بس | — |
| `site_images` | `kind = 'logo' and is_active = true` | `id asc`, `limit 1` |

روابط الصور بتتركب من `bucket` + `object_path` في `publicImageUrl`.

## الكاش

`revalidate: 300` — ٥ دقايق. تعديل سعر من الداشبورد يبان خلال المدة دي.

مكسب جانبي: لو Supabase وقعت أثناء التحديث، Next بيقدّم آخر نسخة ناجحة
بدل ما الموقع يقع.

لاحقًا: إعادة تحقق عند الطلب من الداشبورد بدل الانتظار.

## معالجة الأخطاء

| الحالة | السلوك |
| --- | --- |
| `STOREFRONT_DATA_SOURCE` ناقص أو غلط | خطأ صريح |
| `SUPABASE_URL` ناقص | خطأ صريح |
| مفيش أي مفتاح قراءة | خطأ صريح |
| فشل شبكة | خطأ باسم الجدول ونوع الخطأ بس |
| HTTP ≠ 200 | خطأ بالجدول وكود الحالة |
| شكل غير متوقع | خطأ صريح |
| تجاوز ٨ ثواني | `AbortSignal.timeout` |
| صفر منتجات نشطة | خطأ — متجر فاضي عطل مش حالة |

🔒 **المفتاح ما يدخلش أي رسالة خطأ ولا لوج ولا استجابة.** رسائل فشل الشبكة
بتذكر اسم الخطأ بس من غير الرابط أو الهيدرز.

## الحماية من التسريب للمتصفح

`supabaseServer.ts` و `queries.ts` فيهم `import 'server-only'` — أي محاولة
استيراد من Client Component بتفشل **وقت البناء** مش وقت التشغيل.
