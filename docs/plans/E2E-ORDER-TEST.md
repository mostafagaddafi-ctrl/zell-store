2. **لقطة الطلب** (الأسماء من `0021a_a1_order_cycle.sql` و `0021a_p1_payments.sql`):

```sql
begin;
set transaction read only;
select o.order_number, o.status, o.total_piastres, o.confirmation_fee_piastres, o.paid_piastres,
       o.notified_at is not null as notified, o.notify_error,
       (select pg_catalog.string_agg(p.kind || ':' || p.purpose || ':' || p.amount_piastres, ',' order by p.created_at, p.id)
          from public.order_payments p where p.order_id = o.id) as money_rows,
       (select coalesce(sum(case when p.kind = 'payment' then p.amount_piastres else -p.amount_piastres end), 0)
          from public.order_payments p where p.order_id = o.id) as net_paid,
       (select pg_catalog.string_agg(c.operation, ',' order by c.created_at, c.command_id) from public.zell_payment_commands c where c.order_id = o.id) as commands,
       (select pg_catalog.string_agg(e.kind, ',' order by e.id) from public.order_events e where e.order_id = o.id) as events
  from public.orders o
 where o.order_number = '<رقم الطلب>';
rollback;
```

   **الترتيب ثابت:** الدفعات بـ `created_at` ثم `id`، وأوامر الدفع بـ `created_at` ثم `command_id`، والأحداث بـ `id` (بيزيد بترتيب الكتابة). `created_at` هو وقت بداية المعاملة، فالصفوف اللي في نفس العملية بيبقى ليها نفس الوقت، وعلشان كده فيه عمود تاني يفصل بينهم.
